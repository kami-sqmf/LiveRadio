# Airplay Radio 操作指南

[繁中主文件](README.zh-TW.md) · [English guide](USAGE.md)

文件以英文版為主，本頁為繁體中文版本。

## 第一次連線

1. 在相同播放集啟用 Airplay Radio 與 ExtendedRadio（75862）。
2. 載入城市，開啟遊戲原生電台面板，選擇 Airplay Radio 網路及電台。
3. 確認 iPhone／iPad 與電腦在同一個可信任的區域網路。
4. 開啟手機的 AirPlay **音訊輸出**清單，選擇 `Airplay Radio - 電腦名稱`，再開始播放。請使用音訊輸出，而不是螢幕鏡像。

切換其他電台或停用接收器會中斷接收；切回 Airplay Radio 後，請從手機重新連線。

## 音量與增益

遊戲電台音量與靜音控制電腦端輸出，手機音量控制傳入音訊；兩個介面不互相同步。

聲音太小時，開啟 **選項 → Airplay Radio → 播放 → 音量增益（dB）**：

- 0 dB：原始音量，也是預設值。
- +6 dB：約 2 倍訊號振幅。
- +12 dB：約 4 倍訊號振幅，為最大增益。

調整立即生效，不需重連。峰值限制器會抑制放大後過大的峰值；高增益可能壓縮動態。手機端已靜音的訊號無法靠本機增益恢復。

## 媒體遙控與封面

來源支援手機遙控時，遊戲的上一首、下一首、播放與暫停會傳送給手機。只有基本遙控的來源可能無法持續回報播放狀態。無遙控服務時，暫停只在本機生效；手機仍會繼續播放。

「顯示媒體封面」預設開啟。封面由手機播放器決定是否提供及更新；模組不會上網找圖。沒有封面時使用廣播圖示，左側網路圖示維持不變。

## 通話音訊留在手機

通話的輸出位置由 iPhone 或通話 App 控制。在 iPhone 通話畫面點選「音訊」，選擇手機本身的聽筒或擴音輸出；可參考 [Apple 通話音訊說明](https://support.apple.com/zh-tw/guide/iphone/iph3c9951d7/ios)。其他通話 App 請使用其音訊輸出選單。

Airplay Radio 無法替手機切換通話輸出，也沒有可靠的通話狀態或通話音訊標記。如果來源 App 把通話聲送進同一條 AirPlay 串流，模組無法將它與媒體音訊分開。因此目前不保證自動阻擋所有通話聲；一般電話及各種通話 App 的行為需要分別實測。需要立即停止遊戲端接收時，可關閉「啟用接收」。

## 介面語言

設定選單、播放提示與已知接收狀態跟隨遊戲語言。繁體中文使用中文；英文及其他未翻譯的語言使用英文。曲名、歌手、裝置名稱保留來源文字。

## 疑難排解

| 情況 | 可檢查項目 |
| --- | --- |
| 手機找不到接收器 | 確認已進入城市並選取 Airplay Radio，手機與電腦位於同一區域網路；檢查網路是否隔離裝置。 |
| 找不到電台 | 確認 ExtendedRadio 與 Airplay Radio 在相同播放集啟用，遊戲重啟後查看模組日誌。 |
| 連上但聽不到 | 確認手機正在播放、兩邊未靜音、遊戲電台音量非零；增益不能修復來源靜音。 |
| 無法切歌 | 查看接收狀態，來源可能未提供相容的遙控服務。 |
| 沒有封面 | 確認「顯示媒體封面」已開啟；來源可能未傳送 JPEG／PNG，或超過支援大小。 |
| 偶爾卡頓 | 對照卡頓時間與日誌，區分切歌、暫停、重送及緩衝耗盡；單一累計數值不能確定網路故障。 |

網路變更或連線卡住時可使用「重新啟動接收器」，之後從手機重新連線。

## 診斷與資料

播放時每 15 秒將統計寫入遊戲資料目錄的 `Logs/AirplayRadio.log`。`underruns` 為緩衝耗盡次數，`resendPackets` 含重複重送請求，`decodeErrors` 為解碼錯誤，`gainDb` 為本機增益，`limitedFrames` 為經峰值限制的音訊幀數。

設定與本機接收資料保存在遊戲使用者資料目錄。`ModsData/AirplayRadio` 內含裝置識別、接收金鑰與少量封面快取；請勿將這些個人資料包含在上架套件中。分享日誌前先確認其中的裝置與媒體資訊。

更多驗證證據與限制請參考 [VALIDATION.md](VALIDATION.md)。
