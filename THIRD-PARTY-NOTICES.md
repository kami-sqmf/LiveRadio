## Runtime dependencies and reference material

The UI module uses the game's existing React and CS2 UI/input exports. React,
ReactDOM, TypeScript and esbuild are build/test dependencies and are not bundled
into the distributed module. The module registrar, module header and API shapes
were checked against the StockModTemplatesDiffer template and the installed game.
https://github.com/CitiesSkylinesModding/StockModTemplatesDiffer

Country labels are generated locally using Unicode CLDR display names through
Node.js Intl.DisplayNames (en and zh-TW), with ISO region codes from Windows cultures.
Unicode data license: licenses/UNICODE-LICENSE.txt (https://www.unicode.org/license.txt).

AAC, OGG (Vorbis/Opus), HLS and automatic format detection invoke the user's separately installed
FFmpeg executable through a redirected PCM pipe. No FFmpeg executable or library
is included in this package, and the mod does not download it automatically.
The local checks used FFmpeg 8.1, gyan.dev essentials build, already installed on
the development machine. FFmpeg's applicable license depends on the particular
build and enabled components. See https://ffmpeg.org/ and
https://ffmpeg.org/legal.html for upstream project and licensing information.

ExtendedRadio is a separately installed runtime dependency (Paradox Mods ID 75862).
Its DLL, Harmony DLL and artwork are not redistributed in the LiveRadio package.
The mod references ExtendedRadio's default network icon through its existing
game resource URL. Station artwork is fetched from broadcaster-provided URLs and
cached only on the user's machine; it is not redistributed in this package.
Missing artwork uses an initial icon generated by the mod. ExtendedRadio's public source and documentation were consulted
for integration behavior; its implementation was not copied into this project.

Cities: Skylines II assemblies are referenced from the local game installation
for compilation and are not included in the mod package. Local analysis files
under .work/reference must not be distributed.

Radio Browser provides station directory data; audio comes from the selected
station's stream server. https://www.radio-browser.info/
