## 重要回歸與歷史結果

- **0.4.1 HLS 鎖競爭**：實機 buffer=20 秒、underruns=0，卻有 lockMisses=162 且 RMS=0。0.4.2 改用不取得 producer lock 的讀取；故障注入修正前回傳 0/96,000 樣本，修正後完整輸出。12,582,912 樣本並行順序檢查通過。
- **HLS 與 FFmpeg**：TS、fMP4、master playlist、HTTP AES-128、Auto 與取消清理通過；35 秒移動清單檢查無缺口。0.4.2 真實 HLS／AAC／Opus 各 90 秒遊戲外檢查通過。實機 HLS 105 秒與 66 秒有輸出且無耗盡／丟棄／鎖競爭；較長聽感驗收仍未完成。
- **0.4.3 MP3 重啟**：修正重新連線突發覆寫佇列；單聲道與雙聲道四次快速重啟的 PCM 與參考一致，停止在 3 秒內完成。0.4.3 Antenne 暫停約 135 ms 後恢復，使用者確認短暫等待後順暢。
- **MP3 格式切換**：32 kHz 單聲道與 48 kHz 雙聲道雙向切換控制測試通過。輔大曾出現不一致格式線索，但未錄到原始怪音，0.4.4 短段正常不能證明偶發問題完全排除。
- **0.4.3 圖標**：移除遠端圖標直接進入 UI 的路徑，改為本機快取；0.4.4 再修正明確尺寸／定位。這不解決下載端的內網請求風險。
- **輸入與語言**：原生 change 事件、Checkbox、焦點 barrier、多欄位容器與 IME 防抖替身通過；繁中 Gameface、英文 BCC 實機正常。英文遊戲切換、完整中文組字及 WASD 仍須完整驗收。
- **原生混音整合**：MP3／AAC／Opus／HLS 有接入 Radio 混音群組的紀錄。切回遊戲電台釋放直播、暫停／恢復及收藏保留已有舊版案例；緊急廣播及完整退出流程仍待現版驗收。

## 剩餘驗收

目前版本一般包的完整驗收、乾淨播放集、無 FFmpeg／無網路／缺少相依、較長 HLS、英文／IME、手動收藏與重啟、緊急廣播／退出清理，以及原生解碼調查，統一追蹤於 [發布準備](release-readiness.zh-TW.md)。不得把已開始輸出、非零 RMS 或替身測試寫成完整聽感驗收。
